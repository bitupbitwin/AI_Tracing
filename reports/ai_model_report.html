国产大模型详细选型解读

编程怎么选？
算法、复杂逻辑和高性价比优先考虑 DeepSeek；大型项目、多文件修改和 Agent 工作流优先 GLM、Kimi、MiniMax；重视开源、CLI、API 与国内云平台完整性则优先 Qwen。
图片生成怎么选？
中文海报、商业视觉和多图参考优先 Seedream；文字准确、结构化设计优先 Qwen-Image；商品、人像一致性和阿里工作流优先 Wan Image；电影感角色图和视频衔接可选可灵 Image。
视频生成怎么选？
复杂多镜头、音画联合和导演式控制优先 Seedance；写实人物、运镜和成熟产品体验优先可灵；开发者 API、开源生态与阿里体系优先 Wan；创意视频与语音生态联动可考虑海螺。
文本写作怎么选？
把口述观点整理成脚本或文章优先 Kimi；综合中文写作优先 Qwen；短剧、故事和人物对白优先 MiniMax；抖音、小红书和生活化口语优先豆包；技术分析和商业报告优先 GLM；深度观点拆解优先 DeepSeek。
与 Claude 的差距在哪里？
国产模型在中文互联网语境、生活化表达和本地知识上往往更接地气；Claude 的优势仍主要体现在语言克制、长文节奏、角色语气一致性、复杂改写和较低的“AI 模板味”。

国外大模型详细选型解读

编程应该怎么选？
追求综合代码能力和 Codex 工作流，优先 OpenAI；重视大型项目理解、规划、审查和代码质量，优先 Claude；需要超长上下文、Android、Google Cloud 或 Gemini CLI，优先 Gemini；希望更直接、速度快并尝试新型 Agent，可关注 Grok；企业私有化和开放部署可看 Nemotron、Mistral、Llama。
图片生成应该怎么选？
日常综合生成和自然语言反复修改，优先 GPT Image；追求电影感和艺术审美，Midjourney 仍然很强；制作海报和图片文字，优先 Ideogram；品牌、矢量和设计物料，优先 Recraft；本地部署、LoRA 和高度可控，优先 FLUX 或 Stable Diffusion；Photoshop 工作流优先 Firefly。
视频生成应该怎么选？
原生音画、写实和复杂镜头优先 Veo；专业控制、视频编辑和团队生产优先 Runway；ChatGPT 用户和叙事型画面可看 Sora；快速动态创意可选 Luma；Adobe 用户可直接进入 Firefly 与 Premiere 流程；需要开放权重和本地研究可看 LTX。
文本表达应该怎么选？
长文、润色、脚本、小说、语气控制和减少“AI 味”，优先 Claude；复杂综合任务、分析和工具调用，优先 GPT；一次处理大量资料、网页、图片和长文档，优先 Gemini；偏互联网热点和直接观点表达，可选 Grok；欧洲语言、企业私有化和多语言需求可看 Mistral。
为什么产品榜和纯跑分榜不完全一样？
纯跑分主要测模型在固定任务中的表现；真正使用还受 App、CLI、IDE、编辑器、上下文管理、生成速度、价格、地区开放情况和工作流影响。因此本页把基准能力与产品成熟度合并考虑。
